# GophKeeper

GophKeeper - это безопасное хранилище секретов с gRPC API и CLI клиентом.

## Архитектура синхронизации данных

Система использует упрощенный подход к синхронизации для ускорения разработки MVP.

### Как работает синхронизация

**Локальное хранение:**
- Все секреты пользователя хранятся в одном зашифрованном файле `~/.gophkeeper/data.enc`
- Файл содержит JSON-структуру с массивом всех записей (логины, заметки, карты)
- Каждая запись имеет уникальный ID и временную метку `UpdatedAt` для синхронизации

**Серверное хранение:**
- На сервере хранится полная копия зашифрованного файла для каждого пользователя
- Данные хранятся в PostgreSQL в поле `user_data` таблицы пользователей
- Сервер не расшифровывает данные - работает только с зашифрованным блобом

**Процесс синхронизации (Pull-Merge-Push):**

1. **Pull** - клиент получает зашифрованный файл с сервера
2. **Merge** - объединяет локальные и серверные данные:
   - Создает мапы записей по ID для быстрого поиска
   - Для записей, существующих в обеих копиях, выбирает более новую версию по `UpdatedAt`
   - Добавляет записи, которые есть только на одной из сторон
   - Использует оптимизированный алгоритм O(n)
3. **Push** - отправляет объединенный файл обратно на сервер
4. **Обновление** - сохраняет объединенные данные локально и обновляет `last_sync_ts` в сессии

### Ограничения текущей реализации

С учетом того, что реализовано CLI приложение, а не полноценный клиент с фоновыми процессами, операция синхронизации была намеренно упрощена:

- **Ручной запуск синхронизации** - для выполнения синхронизации необходимо вручную выполнить команду `./keeper sync`
- **Отсутствие автоматической синхронизации** - данные не синхронизируются автоматически при изменениях
- **Защита от конфликтов** - поскольку синхронизация выполняется вручную, пользователь не может одновременно выполнять операции на разных устройствах и испортить данные

Этот подход был выбран для упрощения реализации и ускорения разработки MVP.

## Требования

- Docker и Docker Compose
- Go 1.25+ (для локальной разработки)

## Быстрый старт с Docker

### 1. Настройка окружения

Скопируйте файл примера конфигурации:

```bash
cp .env_example .env
```

### 2. Запуск сервера

Запустите все сервисы (PostgreSQL, Redis, Server):

```bash
make docker-up
```

### 3. Выполнение миграций базы данных

Примените миграции для создания необходимых таблиц:

```bash
make docker-migrate-up
```

Для отката последней миграции:

```bash
make docker-migrate-down
```

### 4. Сборка клиента

Соберите CLI клиент:

```bash
make build-client
```

Это создаст исполняемый файл `keeper` в корне проекта.

### 5. Использование CLI клиента

После сборки клиента вы можете использовать следующие команды:

#### Управление аккаунтом

**Регистрация нового пользователя:**
```bash
./keeper register
```

**Вход в систему:**
```bash
./keeper login
```

**Проверка статуса авторизации:**
```bash
./keeper status
```

**Выход из системы:**
```bash
./keeper logout
```

**Информация о версии:**
```bash
./keeper version
```

#### Управление секретами

**Добавление новой записи:**
```bash
./keeper add
```
Поддерживаемые типы записей:
- `login` - логин и пароль
- `text` - текстовая заметка
- `card` - данные банковской карты

**Просмотр списка записей:**
```bash
./keeper list [type]
```
Где `[type]` - тип записей (login, text, card)

**Просмотр детальной информации записи:**
```bash
./keeper get [id]
```
Где `[id]` - начало идентификатора записи

**Редактирование записи:**
```bash
./keeper edit [id]
```

**Удаление записи:**
```bash
./keeper delete [id]
```

#### Синхронизация

**Синхронизация данных с сервером:**
```bash
./keeper sync
```
Объединяет локальные и серверные данные на основе временных меток.

### 6. Кросс-платформенная сборка

Для сборки клиента под разные платформы используйте следующие команды:

**macOS (Intel и Apple Silicon):**
```bash
make build-client-mac
```
Создаст файлы:
- `dist/client/keeper-darwin-amd64` - для Intel Mac
- `dist/client/keeper-darwin-arm64` - для Apple Silicon

**Linux (amd64 и arm64):**
```bash
make build-client-linux
```
Создаст файлы:
- `dist/client/keeper-linux-amd64` - для Linux x86_64
- `dist/client/keeper-linux-arm64` - для Linux ARM

**Windows:**
```bash
make build-client-windows
```
Создаст файл:
- `dist/client/keeper-windows-amd64.exe` - для Windows x64

**Очистка директории с бинарными файлами:**
```bash
make clean-dist
```

### 7. Дополнительные команды Makefile

**Запуск сервера локально:**
```bash
make run
```

**Выполнение тестов с покрытием:**
```bash
make test
```

**Генерация protobuf файлов:**
```bash
make gen-proto
```

**Генерация моков:**
```bash
make gen-mocks
```
